# 优化路线图

当前项目已覆盖可复现制品、下载校验、GPU/端口预检、容器安全基线、健康等待、API smoke test、
长上下文召回测试和静态 CI。后续优化应以可测量的实际使用需求为准。

## 下一阶段

1. 建立真实业务评测集，覆盖中文问答、coding、JSON 结构化输出、长对话和拒答边界。
2. 验证 OpenAI tools/tool calls 的参数生成质量，但工具执行、审批和沙箱仍由调用方负责。
3. 在 32K/64K context 下测量 `PARALLEL=2`，记录吞吐、首 token 延迟和显存峰值。
4. 为 `/metrics` 接入仅本机可见的 Prometheus/Grafana，增加健康、延迟、token 吞吐和失败率告警。
5. 升级模型或 llama.cpp 镜像时，使用独立分支更新全部固定身份并重新执行 smoke、质量和长上下文测试。

## 暂不做

- 不在 16GB GPU 上把 256K 全 GPU 配置作为常驻服务；
- 不默认增加并发槽位；
- 不直接对公网开放 llama.cpp；
- 不加载多模态 projector，除非重新评估显存和输入安全；
- 不自动追踪浮动镜像 tag、模型分支或未固定的下载地址。
